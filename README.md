# 💼 Employee Management System (Python CLI App)

A lightweight, menu-driven **Employee Management System** built using Python. This command-line application allows users to manage employee records efficiently using file-based persistence and dictionary-based in-memory storage.

## 🚀 Features

- **Add, View, Update, and Delete** employee records
- **Save to file** for persistent data storage
- **Load from file** to restore previously saved data
- **Input validation** and robust error handling
- Clean, **modular function-based architecture**
- Fully **CLI-based interface** for quick interaction

## 🛠️ Technologies Used

- Python 3
- File I/O operations
- Dictionaries and string manipulation
- Error handling with `try-except`

## 📂 Functional Breakdown

- `add_employee()`: Adds a new employee to the in-memory dictionary
- `view_employee()`: Displays all stored employee records
- `update_employee()`: Modifies existing employee details based on user input
- `remove_employee()`: Deletes a specific employee by ID
- `save_to_file()` / `load_from_file()`: Handles data persistence across sessions
- `menu()`: Acts as the main interactive UI loop

## 🧪 Example Usage

```bash
Welcome to the Employment Management System
1. Add Employee
2. View Employee
3. Update Employee
4. Delete Employee
5. Save to file
6. Load from File
7. Exit
```
